# Transfusion OPSD scripts

Use the [current method and work status](/mnt/sdc/stable-audio-tools-workspace/docs/transfusion_opsd.md)
to find the active protocol. Native AR, DiT and planning-state gradients are the
current route; no validated joint candidate has replaced the baseline.

This directory retains the original `prepare_event_opsd_data.py` and
`prepare_event_opsd_holdout_v2.py` data builders. They describe their original
splits; their presence does not make previously consumed requests fresh again.
Current training inputs and the unopened evaluation panel are pinned separately.

Completed release-parity preflights, old whole-audio measurement checks,
seven-action spatial audits and legacy feedback-table rendering were retired.
The [manifest and exact source archive](/mnt/sdc/ckpts/transfusion_opsd/generation_event_coupled_v11_20260909/legacy_code_retirement_v1/MANIFEST.json)
record each deletion. Original reports remain unchanged; previously retired
large artifacts are not restored by the source archive.
